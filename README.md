# Botanique Glow Website System

Open `index.html` in any modern browser. No build step, internet connection, or external image host is required.

## Included
- Responsive desktop/mobile UI
- Local image assets (all images work offline)
- Collection filters and sorting
- Favorites, live search and product quick view
- Cart drawer, quantities, subtotal and free-shipping progress
- Reviews carousel and newsletter validation
- Keyboard focus, Escape handling, reduced motion and accessible labels

## Files
- `index.html` — storefront
- `styles.css` — UI/design system and responsive states
- `app.js` — complete interactive UX
- `assets/` — locally bundled imagery

Checkout and account buttons are frontend prototypes ready for backend integration.
